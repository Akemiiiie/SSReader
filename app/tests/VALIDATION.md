# 里程碑 1 验证记录

日期：2026-09-29；环境：Windows x64、Tauri 开发窗口与本机 Rust MSVC 工具链。

## 已验证

- `npm run build`、`cargo fmt -- --check`、`cargo test` 通过；Rust 自动化 11 项，包含迁移、重复导入、编码预览/改选、超限/损坏文件、位置和书签、备份哈希、恢复中断回滚及向干净数据目录恢复。
- `npm run test:pdf` 验证普通文本、扫描、混合、多栏和旋转 PDF 的页数、旋转信息和逐页文字层状态。多栏的阅读顺序仍需人工核对。
- `npm run tauri:build` 生成 NSIS 和 MSI；`npm run tauri:build:offline` 生成内含 WebView2 离线安装程序的 NSIS 包。
- Windows 开发窗口实际导入并阅读 UTF-8、GB18030 TXT，以及文本、扫描、混合 PDF；GB18030 导入前显示编码不确定提示、正确预览和编码选项，取消选择不会导入。文本页的重排和原页可切换，扫描页保留原页并提示无可选文字，混合 PDF 第 2 页正确切到无文字状态。
- 侧栏可收起和展开；PDF 适页可调整缩放。默认快捷键被本机其他程序占用时，应用成功改用 `Ctrl+Alt+Shift+R`，提示不显示底层 HotKey 异常。
- 开发窗口重启后导入的书籍和阅读位置仍在。验证用书籍已从本机实际书架删除，阅读设置已恢复默认值。
